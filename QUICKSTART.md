## 📱 GAMEPLAY

**[MAIN MENU]**
- 1️⃣ Play Game (New)
- 2️⃣ Continue (Load)
- 3️⃣ Settings
- 4️⃣ Exit

**[IN-GAME ACTIONS]**
1. **Complete Mission** → +$500, +10 Rep ✅
2. **Commit Crime** → +1 Star ⭐, +$200
3. **Escape Police** → 0 Stars
4. **Attack NPC** → -10 Health, +$100
5. **Rest** → Recover Health & Stamina
6. **Return to Menu**

- ⚔️ Attacking NPCs (+$100)

- 🏆 Completing Missions (+10 Rep)

**Get Wanted Stars By:**
- 🚨 Committing Crimes (+1 Star each)

## 🎯 FULL UE5 BUILD

**To play the FULL game in Unreal Engine 5:**

1. Install **Unreal Engine 5.0+**
2. Clone: `https://github.com/Kuvam-Verma/openworld`
3. Open `OpenWorld.uproject`
4. Press **Play** in the editor

**OR build for mobile:**
- **iOS**: File → Package Project → iOS
- **Android**: File → Package Project → Android
