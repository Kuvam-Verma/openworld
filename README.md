# OpenWorld Mobile - iOS/Android Game

## 🎮 QUICK START

**What you have:** A complete mobile open-world game in UE5

**How to play:**
1. **Left Joystick** = Move
2. **Double Tap** = Run (uses stamina)
3. **Tap Attack Button** = Hit enemies
4. **Commit Crimes** = Get wanted stars ⭐
5. **Escape Police** = Lose wanted level

## 📱 Mobile Features

✅ Touch controls optimized for one-handed play
✅ Virtual joystick for movement
✅ Health & Stamina bars
✅ Wanted level system (1-5 stars)
✅ Real-time digital clock (11 time zones)
✅ Money/Score tracking
✅ Simple combat system

## ⭐ Wanted System

```
Commit Crime → Get 1 Star
Max Stars = 5
Stars Decay Over Time
Escape Police → 0 Stars Instantly
```

## ⚙️ Build for Mobile

**iOS (iPhone/iPad):**
```
UE5 → Platforms → iOS → Package
```

**Android:**
```
UE5 → Platforms → Android → Package
```
